# Migration inventory — old Chapters 1–3

## Scope and method

This inventory covers every substantive or structural block in the three chapters
included by `thesis/files/thesis.tex`, using the source files as they existed before
the migration:

- `thesis/files/chapters/1_introduction.tex` (lines 1–170);
- `thesis/files/chapters/2_domain.tex` (lines 1–178);
- `thesis/files/chapters/3_soa.tex` (lines 1–443).

The segmentation follows editorial coherence rather than only LaTeX heading
boundaries. Introductory bridges, substantive paragraphs, marker-bearing passages,
commented template examples, and terminal layout commands are inventoried
separately when they require different migration decisions.

No content was added from a knowledge base. The Documentation KB was queried only
to resolve the classification boundary among APMS/IAP ecosystem context, generic
IHE IUA/SAML/JWT theory, and concrete RVE-1b/RVE-121/RVE-130 transactions. The
graph confirmed that these are distinct concepts, supporting destinations 1.3.2,
2.1.3, and 2.5.2/2.5.4 respectively.

### Notation

- `—` means that the unit contains no item of that kind.
- Commented LaTeX examples are reported as `commented` and are not treated as
  thesis evidence.
- `Control note` denotes a source comment recording an implementation dependency;
  it is not thesis prose or a migration marker.
- Destinations are plausible destinations at inventory stage, not final placement
  decisions. The authoritative decisions are recorded in `migration_matrix.md`.
