# Scryba Sign 3.x Developer's Guide V16

The 113-page Medas developer guide is a restricted internal source. Its original
PDF is retained in the document corpus for authorised local consultation.

The document and unified Graphify knowledge bases contain a sanitised semantic
representation of its integration architecture, SOAP/WSDL services, signing
workflows, session dependencies, authentication constraints, validation
services, and test-data requirements. Generated nodes intentionally exclude
example credentials, private endpoints, certificate secrets, and personal data.
