# Q: How should the Sanita Territoriale Operating Model hyperarc connect COT, PUA, Distretto, Casa della Comunita, and SI.Ter?

## Answer

Expanded via graph vocabulary: [territoriale, centrale, operativa, cot, punto, unico, accesso, pua, distretto, casa, comunita, flussi, siter]. DM 77/2022 documents the Distretto as the functional and organisational coordination level of the territorial network; the Casa della Comunita hosts the PUA; the COT coordinates care transitions and has district relevance. Project documentation describes PUA access demands/referrals feeding COT processes and SI.Ter as the external digital integration project. The conceptual hyperarc therefore contains Distretto, Casa della Comunita, PUA, and COT, while information-flow edges converge toward SI.Ter outside the organisational boundary.
